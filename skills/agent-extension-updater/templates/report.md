# 更新结果模板

检查范围与实际宿主：`<客户端名 + 版本 + 可执行文件真实路径 + profile>`
批准范围与目标：`<用户批准的项目与目标版本；未批准的写"未批准">`
执行时间：`<YYYY-MM-DD HH:mm 时区>`

| 项目 | 原版本 → 实测版本 | 状态 | 验证证据 | 备份与恢复 |
| --- | --- | --- | --- | --- |
| 按实际结果填写 | 读回目标后填写 | 已验证生效 / 已落盘待重启 / 失败 / 跳过 / 检查失败 / 已恢复 | 命令、退出码、读回结果 | 实际本地路径与恢复步骤 |

- 当前运行进程是否已加载新版：`<是 / 否（旧会话不能证明新版本生效）>`
- 失败或未验证的平台与原因：`<逐条说明；无法验证就写"未验证">`
- 需要用户处理的下一步：`<重启、补授权、人工合并本地修改等>`

**禁止**把示例行、预计输出或"应该没问题"当作实际检查结果；报告必须来自真实执行与读回。敏感信息（凭据、个人信息、完整环境配置）一律脱敏。
